# WCS 자동화 목업 시뮬레이터

물류센터의 입고 → 보관 자동분류 → 이커머스 오더 피킹수단 할당 → 출고까지의
흐름을 자동재생 애니메이션으로 보여주는 웹 기반 목업입니다. 실제 최적화
알고리즘 대신, 시나리오 상 규칙 기반 판단을 시각적으로 표현합니다.

## 실행 방법

빌드 과정이 필요 없는 순수 HTML/CSS/JS입니다. 아래 중 하나로 실행하세요.

```bash
# 방법 1: 정적 서버로 실행 (권장 - 새로고침/상대경로 이슈 없음)
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 접속

# 방법 2: index.html을 브라우저로 바로 열기
```

## 주요 화면 구성

- **상단 KPI 바**: 시간당 입고/출고 처리량, 설비 가동률, 오토검수 정확도
- **컨트롤 바**: 재생/일시정지, 배속(1x/2x/4x), 수동 입고 트럭/오더 발생 버튼
- **중앙 맵**: 입고도크(자동입고장치존/일반하차장) → 입고분류 AI → 4-Way
  Shuttle·팔레트랙 / HAIPICK Climber 보관존 → 오더분석 AI → 피킹카트/AMR/
  HAIPICK 피킹 분기(스마트글라스 배정 표시) → 패킹/오토검수 → 출고도크 자동배정
- **우측 이벤트 로그**: ASN 수신, 도크 배분, 보관존 판정, 피킹수단 할당,
  출고 완료 등 시스템 판단을 실시간 로그로 표시
- 지도 위 트럭/팔레트/카트/AMR을 탭(클릭)하면 상세 정보 툴팁이 표시됩니다.

## 파일 구조

```
index.html          레이아웃
css/style.css        전체 스타일 (다크 관제실 테마)
js/data.js            레이아웃 좌표, SKU/운송사 목업 데이터
js/utils.js           SVG/애니메이션 유틸, 엔티티 정보 등록
js/svgMap.js           정적 맵(도크, 존, 랙 그리드) 렌더링 + 슬롯 할당
js/engine.js            입고/출고 시나리오 상태머신 (자동 반복 재생)
js/ui.js                 이벤트 로그, KPI, 툴팁, 컨트롤 바인딩
js/main.js               부트스트랩
```
